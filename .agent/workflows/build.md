# Build Workflow

This workflow commits changes, pushes to remote, and builds the frontend.

## Steps

1. Stage all changes:
```bash
git add .
```

2. Commit with a message (replace `<message>` with your commit message):
```bash
git commit -m "<message>"
```

3. Push to remote:
```bash
git push
```

4. Build the frontend:
```bash
npm run build
```
